# Проєкт data_processing_engine

Проєкт для потокової обробки та аналізу даних про продажі з файлу sales.csv з використанням ітераторів, генераторів та сервісних функцій

## Структура проєкту

* `iterators/` - клас запису продажу SaleRecord та ітератор SalesIterator
* `generators/` - генератори читання csv, фільтрації, підрахунку виручки, розбиття на пакети та формування топ товарів
* `services/` - аналітичні функції (кількість продажів, виручка, середній чек, популярний товар, прибуткова категорія, топ 5)
* `bonus_task/` - додаткові генератори, порівняння використання пам'яті та конвеєр обробки даних
* `sales.csv` - вхідні дані про продажі
* `main.py` - запускає аналітику та додаткові завдання
